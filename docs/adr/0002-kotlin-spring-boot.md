# Kotlin + Spring Boot jako stack aplikacji

Aplikacja powstaje w Kotlinie na Spring Boot, bo oba są znane autorowi, a Spring Boot daje gotowy harmonogram, konfigurację, klienta HTTP i ścieżkę do przyszłego UI. Rozważano Javę (mniej zwięzłego kodu), Pythona (trudniejsze pakowanie na Windows) i Go (brak znajomości i mniej gotowych elementów do UI).
